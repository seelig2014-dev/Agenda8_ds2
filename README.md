# 📚 Agenda 8 — Desenvolvimento de Sistemas II

## 🎓 Apresentação do Projeto

Este repositório foi desenvolvido como parte da atividade da disciplina de **Desenvolvimento de Sistemas II**.

A atividade teve como objetivo apresentar o projeto desenvolvido durante a disciplina, explicando de forma simples e organizada seu funcionamento, as tecnologias utilizadas e os principais recursos implementados.

Para realizar a apresentação, foram produzidos **slides explicativos e um vídeo de apresentação**, reunindo as principais informações sobre o sistema.

---

## 🎯 Objetivo da Atividade

A proposta da atividade foi criar uma apresentação capaz de explicar o funcionamento do programa para outras pessoas, apresentando de maneira clara:

* O objetivo do sistema;
* O funcionamento do programa;
* As principais funcionalidades;
* As tecnologias utilizadas;
* A organização do projeto;
* O funcionamento das principais partes do sistema;
* O resultado final do desenvolvimento.

---

## 🖥️ Materiais Desenvolvidos

O projeto conta com dois materiais principais:

### 📊 Slides

Foi criada uma apresentação contendo informações sobre o programa e seu funcionamento.

Nos slides são apresentados os principais pontos do projeto, utilizando uma linguagem simples e recursos visuais para facilitar a compreensão.

### 🎥 Vídeo

Também foi produzido um vídeo explicativo apresentando o projeto.

O vídeo utiliza os slides como apoio visual e apresenta uma explicação sobre o funcionamento e as características do programa.

---

## 🛠️ Ferramentas Utilizadas

### 🎨 Canva

O **Canva** foi utilizado para desenvolver os slides da apresentação, permitindo organizar textos, imagens, elementos gráficos e a identidade visual do trabalho.

### 🔊 Balabolka

O **Balabolka** foi utilizado para produzir a narração em áudio da apresentação.

A ferramenta permitiu transformar o texto preparado para cada parte dos slides em uma narração, que posteriormente foi utilizada na produção do vídeo.

## 🎬 Desenvolvimento da Apresentação

A apresentação foi desenvolvida seguindo algumas etapas:

1. Organização das informações sobre o programa;
2. Criação dos slides no **Canva**;
3. Preparação do texto utilizado na apresentação;
4. Geração da narração utilizando o **Balabolka**;
5. Organização dos áudios juntamente com os slides;
6. Produção do vídeo final;
7. Organização dos arquivos para disponibilização no GitHub.

---

## 💡 Aprendizado

A realização desta atividade possibilitou colocar em prática não apenas os conhecimentos relacionados ao desenvolvimento de sistemas, mas também habilidades de **organização, comunicação e apresentação de um projeto**.

A criação dos slides e do vídeo ajudou a apresentar o funcionamento do programa de uma forma mais visual e fácil de compreender.
